本单是新的开发就绪执行任务，不是延续此前只读评审；不扩大技术范围或绕过批准门槛。
允许整理文档、完善 G0 批准迁移与测试、在原 PR 内追加提交、更新相关 Issue 的事实状态。
不另开一个仅用于本单的 PR；未来 G1 实现对应独立 PR。

子工作单必须包括以下内容：

| 项目 | 必须明确的内容 |
|---|---|
| 输入 | 批准配置路径、schema 版本、内容标识及可核实的 G0 提交；禁止复制另一套参数默认值 |
| 范围 | Python 旋转刚体、执行器响应、IMU 和组件级测试；默认在 01_simulation/b0 下隔离遗留资产 |
| 边界 | 不实现估计器、PID、C++ 控制核心、闭环 runner、G3 指标器；不增加平移/导航/硬件/论文范围 |
| 接口 | G0 reset/step 和消息字段映射、状态所有权、错误输入保持状态、单位与时间戳 |
| 动力学验收 | 零力矩/静止、可解析的定轴运动、正负轴符号、四元数范数与 q/-q 等价、步长减半检查 |
| 执行器验收 | 一阶响应解析参考、边界值、held command 原 timestamp 与反馈配对；controller 仍是唯一限幅责任方 |
| IMU 验收 | 质心静止比力 [0,0,-g]、旋转坐标变换、陀螺角速度、噪声/偏置语义、采样和 seed/reset 可重复性 |
| 时序验收 | 启动与 R=1000/1001 reset 的局部相位、全局时钟、无 reset-tick step、首个有效采样及旧缓存清除 |
| 数值判断 | 每项 oracle、绝对/相对容差、单位、时间范围及依据；实施前确定，禁止看到结果后为通过而修改 |
| 交付与证据 | 文件落点、track 内命令、CI 接入计划、解析误差和收敛记录格式、PR 与 RESULTS.md 更新边界 |
| PR 组织 | 一个 G1 实施 PR，建议 codex/b0-g1-plant-imu；以合并后 main 为起点，依赖 G0，完成后独立评审 |
