## 实施顺序

### 一 资产审计与模型决策

逐项检查拟复用的仿真、姿态数学、控制、测试和构建资产，记录路径、
实现程度、实际证据及复用/适配/参考/移除候选决定；本 PR 不执行无关删除。
声明绕质心旋转、抽象机体系力矩、IMU 位置、平移加速度与杆臂假设。
选定惯量、积分方法和步长、执行器响应及限值、IMU 噪声/偏置约定与初始状态。
参数区分文献来源、实测来源和合成假设，并解释用于本实验的合理性。

文献优先复用 literature/ 历史记录，遵循 literature/protocol.md；使用具体
公式或参数时核验原文位置。候选摘要不能充当已验证的参数来源。无匹配文献
时可提出明确的合成对象，不得伪称真实机型；不提交受版权保护的全文。

### 二 接口和时序合同

覆盖指令、IMU、估计状态、力矩请求、执行器反馈、评估真值的字段和所有权。
固定 NED/FRD、SI、Hamilton 标量在前四元数及 q_nb 方向，明确反馈角速度来源。
给出 reset/step 签名约定、初值、有限性/维度检查、时间戳、过期和错误 dt 策略。
冻结整数 tick 的一步更新顺序、初始 tick 和控制作用区间，避免前视与代数环。
区分要求力矩、限幅目标、实际力矩，指定抗饱和所用信号及时延。
约定四元数误差方向、q/-q 等价、半周附近处理、PID 微分/积分状态及复位规则。
给出以后 G3 验证真值隔离的测试设计，不宣称本 PR 已验证运行时隔离。

### 三 场景与验收矩阵

覆盖总工作单八类场景：静止、初始偏差、三轴正负阶跃、外部力矩扰动、
IMU 噪声/偏置、饱和撤回、加速度污染、错误输入/复位。
每个场景给出明确配置、时长、事件时间、种子策略、观察信号、指标公式、
时间窗口、容差/阈值、预期行为及负责实现检查的阶段。
区分包线内性能验收、包线外限制刻画和无效输入检查，均须有明确判据。
明确未收敛、零阶跃超调不适用、执行错误的表示；不得将其算作通过。
三轴跟踪和估计误差分开，偏航仅作初始参考下相对跟踪与漂移评价。
登记调参场景与保留验收场景/种子；不承诺统计显著性或预设 Monte Carlo 数量。

逐项审查 CTL-REQ-001/002：适用、条件化适用或不适用，保留原阈值与理由。
即使旧要求不适用，B0 工程通过值也必须提出并审查，不允许只收集曲线而没有判据。
冻结增益字段、单位、允许范围及初始候选值；G2 可以在已批准包线和验收值不变
的前提下调增益并记录版本。初始候选增益不是已验证性能或最终发布参数。

### 四 可执行配置校验与 CI

实现配置加载、规范化和可定位到字段/场景的错误信息。检查至少包括：

- 必需字段、schema 版本、未知字段策略、维度和有限数值；拒绝 NaN/Inf。
- 惯量对称正定；有效四元数及范数处理策略；正步长、时长和采样周期。
- 噪声/偏置单位，非负噪声，正执行器时间常数与有意义的限值。
- 事件顺序和运行区间、整数 tick 一致性、种子类型、观察窗和持续时间的关系。
- 所有场景引用存在且唯一，验收值与指标类型兼容；非法配置不能静默回退。

对每类约束至少提供有效输入及有针对性的非法输入测试；覆盖边界和跨字段错误。
测试配置校验本身，不用未实现的算法作为 oracle。文档中的命令实际运行后再记录。
CI 在对应 track 中运行 pytest，G0 检查不得 continue-on-error；保留就绪探针及
遗留回归策略，分别报告，不能把导航预期失败当作 G0 实现证据。
