# B0 姿态闭环基线工作单

日期：2026-10-09。状态：开发就绪后的执行工作单；G0 合同及验收参数仍需审查冻结。
负责人：Chi Zhang。执行状态以 GitHub Issues 为准。

本工作单将 [B0 v0.2](../development_baseline.md) 分解为可执行工作。
目标是交付可复现的姿态估计与级联控制闭环。工作单完成不代表算法、
验证门槛或性能要求已经完成。本文不新增系统需求编号。

开发前提引用 [开发就绪报告](../development_readiness_report.md) 和
[环境说明](../development_environment.md)：工具链、绑定及 IDE 调试已验证。
这些探针不计入 B0 算法验收；仅在环境或依赖改变时重验受影响部分。
工程目标是在声明的旋转实验包线内完成可测试、可复现的估计状态反馈闭环，
不是完整飞控、实机适航保证或算法创新证明。

## 交付范围

闭环为：姿态指令 → 姿态环 → 角速度环 → 执行器模型 → 旋转动力学
→ IMU → 姿态估计 → 控制器。真实状态仅用于传感器生成及独立评估。

包含旋转动力学、基础姿态融合、C++ 级联控制、限幅与抗积分饱和、
确定性调度、自动化验证和证据输出。不包含位置飞行、完整导航、
PX4、板端、HIL、学习算法、论文与通用验证套件接入。

## G0 必须冻结的合同

1. 沿用 NED、FRD、SI、标量在前的 Hamilton 四元数；明确角速度所在坐标系。
2. 状态为姿态四元数和机体系角速度；惯量对称正定，参数注明来源或合成假设。
3. 使用旋转刚体方程；选择积分方法，并规定步长减半的数值收敛检查。
4. 第一版执行器采用有界机体系力矩及简单响应动态；不宣称完成真实电机分配。
5. IMU 定义噪声是每样本标准差还是谱密度，并明确换算、偏置、种子及采样规则。
6. 声明旋转实验的平移加速度假设。加速度计测比力，不能在任意运动下等同重力。
7. 估计器初始状态由配置提供；六轴 IMU 无法提供绝对航向观测，偏航单独评价。
8. 姿态环建议使用四元数误差产生受限角速度目标；角速度环采用 PID，
   明确微分滤波及抗积分饱和方式。比较姿态时处理 q 与 -q 等价。
9. 冻结 plant/IMU/estimator/controller 的周期与执行顺序，使用整数 tick，
   不按宿主机 wall clock 推进仿真；离散时刻数据不得形成非预期前视。
10. 明确非有限输入、无效/过期样本、错误 dt、初始化及 reset 行为。
11. 定义要求力矩、限幅目标、实际力矩的区别，明确抗饱和反馈取自何处。
12. 冻结验收参数后才调参；任何变更都保留原因，并重跑受影响场景。

采样率、惯量、执行器时间常数、限幅、噪声、增益和初始误差均由 G0
设计记录确定，不在当前工作单中写成未经论证的性能承诺。

### G0 退出与批准规则

- 每个场景登记输入、适用包线、配置位置、指标公式、单位、观测窗口、
  通过条件、测试入口和预期证据位置。数值通过条件不得在 G0 退出时仍为 TBD。
- 区分必须达到性能的包线内场景、刻画能力限制的包线外场景及无效输入测试。
  限制场景不要求任意扰动下恢复，但必须有预先定义的报告、状态或拒绝行为检查。
- 实现者提出惯量、步长、噪声、限幅和验收值及依据；维护者在 G0 PR 中审查
  批准。文献参数、合成测试参数和实测参数分别标注，不把合成对象称为真实机型。
- 对 CTL-REQ-001/002 逐项记录适用、条件化适用或不适用及理由；不适用时仍需
  批准 B0 自身的工程验收值，只是不宣称满足旧需求。不得以“只报告指标”代替验收。
- G0 完成的是可执行配置校验和已审查合同，不要求尚未实现的算法测试提前通过。
  后续实现后相应检查必须成为强制检查；调整阈值须审查并保留原失败证据，不能为使结果通过而静默放宽。

### 必须明确的接口边界

G0 接口表逐一列出指令、IMU、估计状态、力矩请求、执行器状态的字段、
坐标系、单位、时间戳、有效性、所有权与 reset/step 行为。角速度反馈来自
声明的测量或估计路径，不可来自对象真值。采样顺序须说明控制量在哪个积分区间
生效；先使用单一基础 tick，只有明确需要时才引入整数倍多速率。

明确四元数误差乘法顺序、表达坐标系、最短旋转选择，以及接近半周转角时的
确定性处理；若不属于跟踪验收包线，仍需测试输入处理。微分项的输入、滤波状态、
积分限值以及限幅/动态执行器反馈时序必须一致。错误输入检查须定义是否保持状态、
输出状态码或终止运行，不把开发仿真的终止策略描述为实机故障安全策略。

本对象是绕质心的旋转实验，力矩是抽象输入；不计算电机混控、推力分配或位置。
IMU 的位置假设须明确；若置于质心，记录忽略杆臂效应的边界。
加速度污染使用明确的外生测量场景，不因此引入完整平移动力学。

## 场景与判定设计

以下名称为场景标签，不是系统需求 ID。

| 场景 | 核心检查 | 必须保留的指标 |
|---|---|---|
| 静止与零指令 | 反馈符号、平衡与数值漂移 | 姿态/角速度误差、四元数范数 |
| 初始姿态偏差 | 初始化后的恢复 | 峰值误差、恢复时间、力矩 |
| 单轴正负阶跃 | 方向、跟踪与轴间耦合 | 稳态误差、超调、调节时间 |
| 外部力矩扰动 | 抗扰与恢复 | 误差峰值、恢复过程、饱和持续时间 |
| IMU 噪声与偏置 | 估计误差传播至控制 | 姿态误差、偏航漂移、控制波动 |
| 饱和后指令撤回 | 抗积分饱和有效性 | 积分状态、恢复时间、控制输出 |
| 加速度污染 | 倾斜修正失效边界 | 估计误差、修正状态、闭环影响 |
| 错误输入与复位 | 明确失败与可重复初始化 | 异常/状态码、复位后轨迹一致性 |

调节时间定义必须包含误差带、持续时间和观测区间；超调只对定义清晰的
非零阶跃计算。始终未收敛的用例不得伪造有限调节时间。异常运行、
适用性不足和性能失败分别报告。加速度污染用例可用于刻画限制，
不默认要求基础估计器在任意污染下恢复。

CTL-REQ-001/002 的旧阈值须经过适用性审查；未通过审查时，只报告开发
指标，不报告需求符合性。随机实验先声明目的和种子集合；不预设大规模
Monte Carlo 数量。重复性按同环境重复、跨环境数值容差分别评价。

三轴分别定义跟踪口径；偏航以给定初始参考下的相对跟踪和漂移评价，不能
把已知初始航向当作持续绝对航向观测。噪声及偏置场景分别保留估计误差与跟踪
误差，避免两者相互掩盖。G0 同时确定固定回归种子与调参场景，最终验收保留
不用于调参的检查场景或种子；这不是统计置信度或大规模 Monte Carlo 声明。

真值隔离同时检查接口和运行路径：控制器/估计器接口不接收 truth 对象；
固定 IMU、指令及初始化输入时，仅改变评估端真值副本不得改变控制输出。
初始化真值例外须显式记录，初始估计偏差场景必须保留，不能每步重新注入。

## 检查与停止规则

组件完成后立即加入强制 CI；保持既有导航合同回归，不能用其预期失败

全部门槛通过后冻结 B0 版本。扩展、硬件和论文不阻塞发布。
若某项只能通过引入位置飞行、完整导航或其他扩展才能满足，应先审查
场景适用性和范围，不直接扩大 B0。
