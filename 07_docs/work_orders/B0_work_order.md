# B0 姿态闭环基线工作单

日期：2026-10-09。状态：工作单草案；已选择 Windows 编辑与 WSL2/Linux 执行，工具链待验证。
负责人：Chi Zhang。执行状态以 GitHub Issues 为准。

本工作单将 [B0 v0.2](../development_baseline.md) 分解为可执行工作。
目标是交付可复现的姿态估计与级联控制闭环。工作单完成不代表算法、
验证门槛或性能要求已经完成。本文不新增系统需求编号。

## 交付范围

闭环为：姿态指令 → 姿态环 → 角速度环 → 执行器模型 → 旋转动力学
→ IMU → 姿态估计 → 控制器。真实状态仅用于传感器生成及独立评估。

包含旋转动力学、基础姿态融合、C++ 级联控制、限幅与抗积分饱和、
确定性调度、自动化验证和证据输出。不包含位置飞行、完整导航、
PX4、板端、HIL、学习算法、论文与通用验证套件接入。

## G0 必须冻结的合同

1. 沿用 NED、FRD、SI、标量在前的 Hamilton 四元数；明确角速度所在坐标系。
2. 状态为姿态四元数和机体系角速度；惯量对称正定，参数注明来源或合成假设。
3. 使用旋转刚体方程；选择积分方法，并规定步长减半的数值收敛检查。
4. 第一版执行器采用有界机体系力矩及简单响应动态；不宣称完成真实电机分配。
5. IMU 定义噪声是每样本标准差还是谱密度，并明确换算、偏置、种子及采样规则。
6. 声明旋转实验的平移加速度假设。加速度计测比力，不能在任意运动下等同重力。
7. 估计器初始状态由配置提供；六轴 IMU 无法提供绝对航向观测，偏航单独评价。
8. 姿态环建议使用四元数误差产生受限角速度目标；角速度环采用 PID，
   明确微分滤波及抗积分饱和方式。比较姿态时处理 q 与 -q 等价。
9. 冻结 plant/IMU/estimator/controller 的周期与执行顺序，使用整数 tick，
   不按宿主机 wall clock 推进仿真；离散时刻数据不得形成非预期前视。
10. 明确非有限输入、无效/过期样本、错误 dt、初始化及 reset 行为。
11. 定义要求力矩、限幅目标、实际力矩的区别，明确抗饱和反馈取自何处。
12. 冻结验收参数后才调参；任何变更都保留原因，并重跑受影响场景。

采样率、惯量、执行器时间常数、限幅、噪声、增益和初始误差均由 G0
设计记录确定，不在当前工作单中写成未经论证的性能承诺。

## 场景与判定设计

以下名称为场景标签，不是系统需求 ID。

| 场景 | 核心检查 | 必须保留的指标 |
|---|---|---|
| 静止与零指令 | 反馈符号、平衡与数值漂移 | 姿态/角速度误差、四元数范数 |
| 初始姿态偏差 | 初始化后的恢复 | 峰值误差、恢复时间、力矩 |
| 单轴正负阶跃 | 方向、跟踪与轴间耦合 | 稳态误差、超调、调节时间 |
| 外部力矩扰动 | 抗扰与恢复 | 误差峰值、恢复过程、饱和持续时间 |
| IMU 噪声与偏置 | 估计误差传播至控制 | 姿态误差、偏航漂移、控制波动 |
| 饱和后指令撤回 | 抗积分饱和有效性 | 积分状态、恢复时间、控制输出 |
| 加速度污染 | 倾斜修正失效边界 | 估计误差、修正状态、闭环影响 |
| 错误输入与复位 | 明确失败与可重复初始化 | 异常/状态码、复位后轨迹一致性 |

调节时间定义必须包含误差带、持续时间和观测区间；超调只对定义清晰的
非零阶跃计算。始终未收敛的用例不得伪造有限调节时间。异常运行、
适用性不足和性能失败分别报告。加速度污染用例可用于刻画限制，
不默认要求基础估计器在任意污染下恢复。

CTL-REQ-001/002 的旧阈值须经过适用性审查；未通过审查时，只报告开发
指标，不报告需求符合性。随机实验先声明目的和种子集合；不预设大规模
Monte Carlo 数量。重复性按同环境重复、跨环境数值容差分别评价。
