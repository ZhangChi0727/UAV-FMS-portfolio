# Learned angular-rate forecaster

**State: in preparation. No model has been trained and no result exists.**

## Question

On data generated by the B0 plant, actuator and IMU models, does a small learned model forecast the body-x
angular rate over the next 100 ms (20 steps of 5 ms) better than physics baselines, and does it keep working
when inertia or actuator lag is shifted outside the training cells?

## Planned comparison

| Arm | Description |
|---|---|
| M1 | Nominal physics update |
| M2 | Physics update with parameters fitted on training data |
| M3 | Small MLP added to the predicted rate |
| M4 | The same small MLP added to the frozen M2 step |

## Design rules

- Inputs are gyroscope readings, validity flags and already-published torque commands only. Truth is held by the
  evaluator and is never a model input.
- Trajectories are split before windowing; out-of-distribution cells (inertia shift, lag shift) and a noise shift
  are held out.
- Failures are counted and a coverage gate decides whether accuracy is reported as comparable.
- Latency is measured with a fixed CPU, thread count, warm-up and repetition count.

## Limits

Single axis, synthetic data, host CPU. The study is offline prediction and evaluation; it does not enter any
controller or estimator and makes no statement about flight.
