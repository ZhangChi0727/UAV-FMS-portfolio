# G1.5-C reader visual acceptance

Date: 2026-10-13 (Australia/Perth)

Scope: temporary HTML generated by
`tools/systems_engineering/check_g15c_traceability.py` from the controlled
ledger and report source. The HTML and PNGs were generated under `build/` and
are not repository deliverables.

## Actual inspection

| Viewport | Renderer | Result |
|---|---|---|
| 1280 × 720 | local Playwright with installed Chrome, headless | pass |
| 1440 × 900 | local Playwright with installed Chrome, headless | pass |

The first screen exposes the controlled-view boundary, design-link denominator,
executed-specification denominator, accepted-evidence denominator, requirement
satisfaction denominator and the current gap. The 1440 × 900 view also exposes
the first execution-record card; the 1280 × 720 view reaches it through normal
vertical scrolling. Neither viewport has horizontal overflow, overlapping text,
unrendered Markdown markers or content hidden behind fixed controls. Long text
wraps inside cards, headings and status are not communicated by color alone,
and the monospace Vim-style font stack does not use Times New Roman or a CJK
font for Western text.

The first attempted render revealed literal Markdown emphasis and an empty
execution-record section. The HTML generator was corrected and both viewports
were re-rendered before this acceptance record was written.
