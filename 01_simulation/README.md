# Simulation

B0 owns rotational plant, sensor, actuator and environment models with deterministic IMU scenarios. Existing scenario_generator files are legacy scaffolds. Full translation, fixed-wing dynamics and MATLAB integration are optional extensions.

See [baseline](../07_docs/development_baseline.md), [architecture](../07_docs/architecture.md) and [extension registry](../07_docs/roadmap.md).

Status: planned; existing scaffold paths are retained for compatibility.
