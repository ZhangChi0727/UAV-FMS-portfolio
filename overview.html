UAV FMS Portfolio

Two independent tracks are maintained:

  • B0: historical component-level dynamics, estimator and C++17 controller evidence. Component acceptance is not whole-system or flight acceptance. Historical closed-loop material is retained in tag pre-surgery-2026-11-22.
  • EDGE: the Day 1–4 pipeline trained a CODEBRIM detector, pruned and quantized it, profiled four variants on the development host, and replayed cached predictions. The technical note separates annotation-relative scores and measured host latency from modeled network latency and energy. See the EDGE README for the modules supporting EDG-REQ-0034-0041.

Systems-engineering source is requirements. The compact requirements view can be opened offline. Maintain NED/body conventions, SI units and scalar-first Hamilton quaternions; truth is excluded from controller and estimator inputs except initialization.

Run pytest within each B0 track directory. Build and test the C++ controller using its CMake presets. Export requirements using strictdoc export requirements --output-dir build/strictdoc-check. Report actual host, commands and raw results for measurements.
